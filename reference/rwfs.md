# WFS client for R

This R package provides a client to access Web Feature Services (WFS)
(<http://www.opengeospatial.org/standards/wfs>).

## Details

The client relies on the GDAL (<http://www.gdal.org/>) library and the
rgdal (<https://cran.r-project.org/package=rgdal>) package, which should
be installed first.

See examples in the fmi (<http://www.github.com/rOpenGov/fmi>) and the
gisfin packages (<http://www.github.com/rOpenGov/gisfin>) how to inherit
the abstract R6 classes (<https://cran.r-project.org/package=R6>)
provided by the package.
